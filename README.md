# Taller-Final-202205241
Proyecto Gestión de Partidas, desarrollado en Python mediante programación orientada a objetos. Incluye el análisis y los requerimientos del programa, el diagrama de flujo y la implementación del código para registrar los datos de un videojuego, mostrar su ficha técnica e iniciar la sesión de juego.
# Fase 1: Análisis y requerimientos
En esta primera fase realicé el análisis del proyecto Gestión de Partidas, identificando su objetivo y el funcionamiento de la clase SesionJuego. Definí sus atributos (título, categoría y sistema), sus métodos principales y los requerimientos funcionales y no funcionales necesarios para el funcionamiento del programa.
# Fase 2: Diagrama de flujo
En esta fase elaboré el diagrama de flujo para representar visualmente la secuencia del programa. Incluí la creación del objeto SesionJuego, la presentación del menú, las opciones para mostrar la ficha técnica del videojuego y para iniciar el juego, utilizando Minecraft como ejemplo.
# Fase 3: Código del programa
En esta fase trabajé en la implementación del programa en Python utilizando programación orientada a objetos. El programa utiliza la clase SesionJuego para almacenar los datos del videojuego y los métodos ficha_tecnica() y arrancar() para mostrar su información e indicar el inicio de la sesión. Como ejemplo, utilicé Minecraft, de categoría Supervivencia, en la plataforma Xbox.
# Fase 4: Publicación del proyecto en GitHub
En esta fase subí a GitHub los archivos que realicé durante el desarrollo del proyecto Gestión de Partidas. Organicé y publiqué el análisis y los requerimientos, el diagrama de flujo y el documento correspondiente al código del programa. También agregué las descripciones de cada fase en el archivo README.md, con el propósito de documentar el proceso de desarrollo y mantener todos los materiales del proyecto organizados en un solo repositorio.
